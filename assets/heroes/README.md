# GeoHub page hero images

These banners were created with the built-in imagegen tool for the Laudato Si’ Action Platform GeoHub for Integral Ecology.

## Revised visual direction

Flat 2D abstract cutout shapes with subtle shadows, full-color teal and green backgrounds, almost no white or cream, cartographic contours, rivers, leaves, and community motifs. The quieter dark teal area on the left is intended for a white HTML page heading. Images contain no embedded titles.

Palette: #18a177, #044f53, #50c6bc, #03666e, #e6e2db, #ef5931, #f9b024, #fcf4ec.

Use the files ending in `-flat.png`. `home.png` is the earlier cream-background draft and is excluded from the final collection.

## ArcGIS Hub use

Upload the selected PNG as a page row background. Use a white Avenir title over the quieter left side. Keep the image centered and check the mobile crop; headings should remain real page text rather than part of the image.
